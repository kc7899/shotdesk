# 资料依据

整理日期：2026-10-27。只提炼方法，未复制课程或剧本正文。教学、竞赛与创作者经验适用范围不同；本Skill针对短剧工作台取舍，不把长片投稿排版或某位作者的偏好当统一强制标准。

- [BBC剧本格式示范](https://downloads.bbc.co.uk/writersroom/scripts/screenplay.pdf)：场景、动作、人物和对白的区分；把叙述落实为银幕事件。
- [奥斯卡学院Nicholl评审维度](https://www.oscars.org/nicholl/about)：故事、人物声音、行动动机、戏剧技巧及情感效果。仅借鉴质量维度，不表示AI剧本符合竞赛资格。
- [圣丹斯短片剧本课程](https://collab.sundance.org/catalog/Crafting-Your-Short-Film-Screenplay/October-2026)：人物需要、阻碍、场景目标、动作对白、开头结尾和重写。
- [圣丹斯重写课程](https://collab.sundance.org/catalog/Screenwriting-Rewriting-Your-Feature)：行为、潜台词、信息交代与场景修改。
- [BFI剧本编辑经验](https://www.bfi.org.uk/features/writing-tips-from-top)：初稿后的反馈和修订。
- [BFI Film Academy短片构思](https://www.watershed.co.uk/film-academy/labs/developing-your-idea-into-a-winning-short-film-script/)：人物困境、基调与结构。
- [BAFTA/BFI Peter Straughan讲座](https://static.bafta.org/uploads_pre_202411/transcripts/24_oct_2010_screenwriters_lecture_by_peter_straughan.pdf)：文学改编中的视听重新组织。
- [Final Draft剧本元素](https://www.finaldraft.com/learn/screenplay-formatting-elements/)：场景、简洁动作及明确说话人。
- [中国作家网微短剧创作经验](https://www.chinawriter.com.cn/n1/2024/0711/c441011-40276066.html)：集中主线、人物、戏剧张力和场景可实现性。
- [DeepMind Dramatron](https://github.com/google-deepmind/dramatron)：结构上下文、人工编辑及公式化输出局限。没有移植其多轮生成流程，不据此承诺自动审核有效。
