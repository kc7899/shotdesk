# 0.1.0-preview.1

这是供已有本地模型服务的用户和 Agent 试用的预览版本，不是任意云端 API 的通用客户端。发布包可从本仓库 Releases 下载并本地安装。

## 本版支持

- 内容、剧本、资产、分镜、可选首帧、视频和合片。
- OpenAI 兼容文字服务、真实模型列表和可选 API Key。
- ComfyUI API 工作流导入、输入映射、依赖检查；图片、文字生视频、首帧与资产参考模式。
- 角色身份、造型与可选声线；任务历史、版本采用、共享已读和独立完成标记。
- 持久任务队列、任务级停止、服务重启后的有界恢复。
- 中文/English 界面；界面语言与创作语言分开。
- 可执行诊断/配置工具、部署 Skill 与两镜头验收工具。

## 已知限制

- 不安装或分发模型权重、自定义节点、私人素材和私有工作流；用户需准备可用服务。需要 Agent 安装模型时，仍须依据设备、许可证及用户授权选择。
- 当前 main 已新增 Seedance（方舟、Replicate、fal）与 MiniMax H3 官方 V2 的云端视频适配；旧 preview.1 发布包不包含此后续更新。支持文字、首帧、图片资产参考；火山方舟增加显式音频和视频联合参考，视频需配置公网HTTPS素材地址，使用6小时单文件签名链接。协议模拟测试通过，真实付费生成尚待账号验证。任意服务 URL 或任意配音 API 不能自动兼容。
- 通用 ComfyUI/IndexTTS 连接目前不支持独立认证。文字服务密钥和工作台访问密码互不替代。
- 音频/视频参考的专用工作流、精确配音中止不是通用适配器的完整能力；没有输入适配时会拒绝，不伪装支持。
- H3 分镜为结构化创作方案；不同视频模型可能对同一提示词理解不同。参考图与台词关系必须看实际输出，不能仅靠文字校验保证画面质量。
- 连接成功、依赖通过、生成成功、画面合格是不同结论。诊断报告不做视觉质量承诺。
- 不提供多用户权限、自动审核放行或无限重试。生成时间取决于模型、设备与任务。
- 可选历史分镜包和无明确再分发许可的上游提示词原文不随公开候选分发；历史测试在缺少这些可选材料时明确跳过，当前默认方案不依赖它们。

## 验收

单元与 HTTP 集成测试用模拟服务，不代表 GPU 推理。真实模型验收另记录环境、工作流、任务 ID、输出媒体检查和限制；项目中不分发测试生成的媒体或凭据。

运行公开包中的 `scripts/shotdesk_setup.py doctor`，再按 [local-setup.md](local-setup.md) 执行自己的两镜头验收。测试创建单独项目，保留结果供检查。
